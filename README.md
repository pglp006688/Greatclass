##
A software for recording online classes
Offline recorded lecture tool. Teachers can upload videos, which are automatically compressed to 720p and packaged into a single JSON course file; students just import the JSON to start learning, with support for switching episodes, fullscreen playback, and a control bar with resume playback.
### No server required at all—one JSON file equals one course.
- **Teacher side**: Import multiple videos at once, automatically compress to 720p with ffmpeg, embed in Base64, and generate `.gclass.json` with one click
- **Student side**: Just import the JSON to watch, videos auto-decode to a temp folder and are cleaned up after playback
- **Multiple episodes**: Switch freely using the course directory on the right, auto-play next episode
- **Fullscreen playback**: `F` key / double-click / click `⛶` to enter, `Esc` to exit, control bar synced
- **Fully offline**: Videos and covers fully Base64-embedded in JSON, can be shared via WeChat, QQ, or USB
